# FastAPI database patterns

## Sync SQLAlchemy 2.0

```python
# app/db.py
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker, DeclarativeBase
from app.core.config import settings

engine = create_engine(settings.database_url, pool_pre_ping=True)
SessionLocal = sessionmaker(bind=engine, autoflush=False, expire_on_commit=False)

class Base(DeclarativeBase):
    pass

# app/api/deps.py
def get_db():
    with SessionLocal() as db:
        yield db
```

Endpoints and services are `def` (threadpool). Commit explicitly in the service: `db.add(obj); db.commit(); db.refresh(obj)`.

## Async SQLAlchemy 2.0

```python
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker, AsyncSession

engine = create_async_engine(settings.database_url, pool_pre_ping=True)  # postgresql+asyncpg://, sqlite+aiosqlite://
SessionLocal = async_sessionmaker(engine, expire_on_commit=False)

async def get_db():
    async with SessionLocal() as session:
        yield session

@router.get("/{user_id}", response_model=UserOut)
async def read_user(user_id: int, db: Annotated[AsyncSession, Depends(get_db)]):
    user = await db.get(User, user_id)
    if user is None:
        raise HTTPException(404, "User not found")
    return user
```

- Relationship access must be eager: `select(User).options(selectinload(User.items))` or `lazy="selectin"` on the mapping.
- `await db.commit()`, `await db.refresh(obj)`; `await engine.dispose()` in lifespan shutdown.
- Alembic with async engines: generate `alembic init -t async alembic` or adapt `env.py` to `run_sync`.

## SQLModel

```python
from sqlmodel import SQLModel, Field, Session, create_engine, select

class UserBase(SQLModel):
    email: str = Field(index=True, unique=True)

class User(UserBase, table=True):
    id: int | None = Field(default=None, primary_key=True)
    hashed_password: str

class UserCreate(UserBase):
    password: str

class UserPublic(UserBase):
    id: int

def get_session():
    with Session(engine) as session:
        yield session

users = session.exec(select(User).offset(0).limit(20)).all()
```

SQLModel wraps SQLAlchemy and Pydantic; version-pair it with the installed SQLAlchemy/Pydantic (`pip show sqlmodel`). `SQLModel.metadata` is the Alembic `target_metadata`.

## Alembic

```
alembic init alembic                      # once; sets alembic.ini + alembic/env.py
alembic revision --autogenerate -m "msg"  # generate from metadata diff
alembic upgrade head | downgrade -1 | history | current
alembic check                             # fails if models differ from migrations (CI)
```

In `alembic/env.py`:

```python
from app.db import Base
from app import models  # noqa: F401  ensure every model module is imported
target_metadata = Base.metadata
config.set_main_option("sqlalchemy.url", settings.database_url)  # read from settings, not alembic.ini
```

Set `compare_type=True` and `compare_server_default=True` in `context.configure` to detect type/default changes. Review every autogenerated file: renames appear as drop+add; enum changes and indexes may be missed.

## Test databases

| Strategy | How | Trade-off |
|---|---|---|
| SQLite in-memory | `create_engine("sqlite://", connect_args={"check_same_thread": False}, poolclass=StaticPool)`; `Base.metadata.create_all` | fast; dialect differences vs Postgres |
| Transaction per test | open connection, `begin()`, bind `Session` to it, `rollback()` in teardown | real DB, fast, isolates tests |
| Testcontainers | `testcontainers[postgres]` fixture at session scope + Alembic `upgrade head` | slowest, highest fidelity, validates migrations |

Override the dependency rather than patching modules:

```python
@pytest.fixture
def client(db_session):
    app.dependency_overrides[get_db] = lambda: db_session
    yield TestClient(app)
    app.dependency_overrides.clear()
```

For async tests:

```python
@pytest.fixture
async def client():
    async with AsyncClient(transport=ASGITransport(app=app), base_url="http://test") as c:
        yield c
```

Mark tests with `@pytest.mark.anyio` (FastAPI ships `anyio`) or configure `pytest-asyncio` `asyncio_mode = "auto"` in `pyproject.toml`.

## Connection pooling notes

- uvicorn workers are processes; each has its own pool. `pool_size` x workers must stay under the DB connection limit (use PgBouncer when scaling out).
- `pool_pre_ping=True` avoids stale connections after DB restarts.
- Serverless deployments: use `NullPool` or an external pooler.
